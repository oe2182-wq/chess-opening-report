# Piece images

The board uses 12 PNG files here: `wK.png wQ.png wR.png wB.png wN.png wP.png` and the same with `b` for Black.

The published app uses the Chess.com piece set `ejgfv`, with Chess.com's permission to use it in this tool.
That permission doesn't cover redistributing the files, so they aren't in this repository. Add any piece set
with those file names to run the board locally.
